# vue-first-project

This project is a small news application built with Vue.js and Bootstrap that allows Customer Success Managers and Sales teams to quickly understand the latest media coverage of their customers and prospects.

## Install Node
```bash
sudo apt update
sudo apt install nodejs
sudo apt install npm
```

## Install packages
```bash
cd vue-project
npm i
```

## Run json-server
```bash
npm run server-articles
npm run server-accounts
```

## Run dev server
```bash
npm run dev
```
